How to use every button and worksheet

Instructions for this HTML version: Press 2ND then another key for its orange label. This version is not an exact physical-calculator emulator. The small number above each TVM key is its stored value.

Quick start: loan payment

  1. For monthly payments, press 2ND + I/Y, type 12 and ENTER to set P/Y. Use an arrow to select C/Y if needed; enter it and press ENTER. Press CE/C to leave settings.
  2. Type each known value then its TVM key: N (periods), I/Y (annual rate as a percent), PV (loan amount), PMT (payment), FV (ending balance). Give cash paid out a negative sign.
  3. Press CPT then the unknown TVM key to solve. For example, after storing N, I/Y, PV and FV, press CPT then PMT. Press RCL then a TVM key to inspect its stored value.

Worksheet and panel instructions

  • CF: Enter initial CFo and ENTER; ↓ to C01, enter the amount and ENTER; ↓ to F01, enter its repetition count and ENTER. Repeat for C02/F02 and later groups. Use 2ND + ↑/↓ to delete/insert a group.
  • NPV / IRR: NPV opens discount rate I; type a percent and ENTER, then use ↓ to see NPV, NFV, payback PB and discounted payback DPB. IRR shows the internal rate; ↓ to RI to enter reinvestment rate and ↓ to MOD for modified return.
  • AMORT: Press 2ND + PV or 2ND + NPV. Enter P1 (first payment) and P2 (last payment) with ENTER; ↓ shows BAL (balance), PRN (principal) and INT (interest). Stored TVM values and BGN/END setting supply the loan terms.
  • Interest conversion: Open its button below the keypad. Enter NOM (nominal annual rate) and C/Y (compounding periods), then navigate to EFF and press CPT. Enter EFF and CPT on NOM to reverse the conversion.
  • Profit margin: Enter two of CST (cost), SEL (selling price) and MAR (gross margin percent); navigate to the unknown and press CPT. Margin uses selling price as its denominator.
  • Percent change: OLD is starting value, NEW is ending value, CH is change per period in percent, PD is number of periods. Enter known values and CPT on the unknown. Leave PD at 1 for a single-period change.
  • Breakeven: FC is fixed cost, VC variable cost per unit, P price per unit, PFT target profit and Q quantity. Enter known values and CPT on the unknown. PFT=0 gives breakeven quantity.
  • Date panel: Enter start/end dates, choose Actual or 30/360, and press Days between. Enter a number of days and press Add days to start to compute a date using actual calendar days.
  • Statistics panel: Enter one X,Y pair per line, choose LIN, LN, EXP, PWR or 1-V, and press Compute statistics. Results include count, means, deviations and sums; regression adds coefficients and correlation.
  • Bond panel: Enter settlement/redemption dates, annual coupon percent, redemption value per $100, coupon frequency, day-count method and yield. Price returns PRI (clean price), AI (accrued interest) and DUR (modified duration). Enter a clean price and press Yield to solve yield.
  • Memory: Type a value, press STO, then digit 0–9. Press RCL then that digit to recall it. 2ND + 1 opens the memory worksheet.
  • Display format: Open Display format below or press 2ND + 2. Choose 0–8 decimals or Floating and US/European separators. Formatting does not round internally stored TVM values; ROUND does.
  • Scientific strip: eˣ, x!, π, ANS, sin/cos/tan and DEG/RAD act on the displayed value. INV before trig selects inverse; 2ND + INV selects hyperbolic. For nCr/nPr, type n, tap the operation, type r, then =. For CONST, type first value, operator, constant, tap CONST then =; type a new value and = to reuse it. % divides by 100, or applies the percentage to the first number during +/−.

Scope: Depreciation is omitted. Some functions use panels rather than physical key sequences. The file works offline but is not an installable PWA.

TVM: type or calculate, then tap N, I/Y, PV, PMT or FV to store the display; CPT + key solves; RCL + key recalls. Arithmetic defaults to chain order; parentheses group expressions. CONST: enter number, operator, constant, tap CONST and =; type another number and = to reuse it. 2ND + 2 opens display format. In a worksheet, arrows navigate, ENTER stores, CPT computes, 2ND + CE/C clears, and 2ND + CPT quits.
